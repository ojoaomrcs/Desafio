# Portal da Música 🎵

Landing page desenvolvida como parte do Desafio 01 do curso, com o objetivo de apresentar uma escola de aulas particulares de música (violão, piano e canto).

##  Tecnologias utilizadas

HTML5 (semântico)
CSS3 (com Flexbox e Media Queries para responsividade)
Git e GitHub
## 🔗 Links

Site publicado: https://ojoaomrcs.github.io/Desafio/
Repositório: https://github.com/ojoaomrcs/Desafio
##  Sobre o projeto

O site conta com header com navegação, seção hero com chamada para ação, seção sobre, 3 cards de aulas oferecidas, galeria de imagens e seção de contato — seguindo os requisitos de estrutura semântica, acessibilidade e responsividade do desafio.

##  Uso de Inteligência Artificial

Durante esse desafio eu usei o Claude e o Gemini como apoio, mas sempre buscando entender o que estava sendo feito antes de aplicar no projeto. Além da IA, também aprendi bastante assistindo as aulas do curso e usando o material de apoio disponibilizado.

Com o Claude entendi melhor a estrutura semântica do HTML, quando usar tags como <section>, <article>, <header> e <main>, e por que cada uma existe. Também usei ele pra me ajudar a resolver alguns problemas no meio do caminho, como o CSS não estar carregando e imagens dando erro 404, além de aprender boas práticas de commit no Git, como separar mudanças em feat:, style: e docs: em vez de jogar tudo num commit só.

Com o Gemini, usei para criar o corpo do site e me orientar em que partes eu podia estar melhorando.

No fim das contas, a ideia não foi copiar código pronto, mas combinar o conteúdo das aulas com a IA como apoio, usando ela mais como um tutor que me explicava o porquê de cada escolha, pra eu conseguir entender e explicar o próprio projeto depois.
